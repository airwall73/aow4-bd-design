# 《奇迹时代4》自动bd生成器

## 使用方法

1. 下载后丢给AI（最简单的网页版豆包+工作模式就行；deepseek网页版读不了skill，需要DSH；越强的AI效果越好）
2. 说明想做的 BD。AI 会先核对资料日期，尽量在第一分钟内一次问清资料更新、龙王和主战兵种偏好，以及是否允许使用命运幻象、个人崇拜。命运幻象无法在战役中使用；个人崇拜会加快节奏，需万神殿解锁。你可以逐项回答，也可以答“由你决定”。已说明的选择会直接沿用。
3. 问题发出后最多等 2 分钟。漏答或超时的项目默认不用龙王、不使用命运幻象、允许使用个人崇拜，兵种和其他设计取舍由 AI 决定。你已经给出的限制继续生效。支持定时继续的环境会自动往下做；普通聊天若需新消息才能运行，回一句“继续”即可。随后 AI 会批量比较候选兵种，用同一份 `<文档名>.build.json` 核对路线和计算伤害，通过校验后写 BD 正文。交付的 Markdown 和这份伤害记录放在同一目录，后续修订沿用原记录。

例如：
- “做个以僧侣为主战单位的bd”
- “我想要一套重商卡特尔的BD，不要用别的DLC、不要用万神殿解锁的东西”
- “随便推荐一套BD，领袖要龙王+圣徒，要包含最新DLC的全部4本魔典”
- “看下这个老版本的游戏攻略(...)，把其中的bd按新版本数据优化下”

由于skill里有一定关于游戏理解和数据的描述，也可以利用这个skill的知识做些其他交流，比如：
- “用这个skill帮我总结下，有哪些海洋环境用得上的经济建筑”
- “沙漠地图适合哪些单位、哪些魔典，推荐一下”

## 其他说明

- 默认探索至少3个不同的bd思路，然后做取舍，需要AI进行一定时间（实测约20分钟）的思考
- 同一天可复用已查到的官网日期，再与当前内置版本比较。查不到日期时会注明。不想联网可以直接要求使用内置资料。
- 游戏本身没提供API接口，暂无法让AI自己实战测试，所以都是纸上谈兵，**不要指望它能提供完美无瑕的答案**
- 未加入对运营部分的规划功能，目前对英雄的刻画也非常粗糙，主要制作**单兵种+辅助英雄**的常规思路bd
