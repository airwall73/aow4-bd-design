# 《奇迹时代4》自动bd生成器

## 使用方法

1. 下载后丢给AI（最简单的网页版豆包+工作模式就行；deepseek网页版读不了skill，需要DSH；越强的AI效果越好）
2. 许愿。

例如：
- “做个以僧侣为主战单位的bd”
- “我想要一套重商卡特尔的BD，不要用别的DLC、不要用万神殿解锁的东西”
- “随便推荐一套BD，领袖要龙王+圣徒，要包含最新DLC的全部4本魔典”
- “看下这个老版本的游戏攻略(...)，把其中的bd按新版本数据优化下”

由于skill里有一定关于游戏理解和数据的描述，也可以利用这个skill的知识做些其他交流，比如：
- “用这个skill帮我总结下，有哪些海洋环境用得上的经济建筑”
- “沙漠地图适合哪些单位、哪些魔典，推荐一下”

## 其他说明

- 默认探索至少3个不同的bd思路，然后做取舍，需要AI进行一定时间（实测约20分钟）的思考
- 每次运行都会去开源数据minionsart.github.io/aow4db比对更新时间，所以不用担心版本更新后数据过时。不想联网的话可以要求跳过这个步骤
- 游戏本身没提供API接口，暂无法让AI自己实战测试，所以都是纸上谈兵，**不要指望它能提供完美无瑕的答案**
- 未加入对运营部分的规划功能，目前对英雄的刻画也非常粗糙，主要制作**单兵种+辅助英雄**的常规思路bd
