# 动物量产机制

召唤动物不是稳定募兵：随机、地形限定、亚文化联动、特殊建筑解锁都有例外。以动物为量产核心设计BD时必须逐条核对本文件。

## 呼唤动物法术的三选一机制

- 呼唤狂野动物（野兽魔典）：从 T1/T2 动物池召唤；呼唤高级动物（活力魔典）：从 T3/T4 动物池召唤。
- 机制：按施放法术时所在**地形**对应的池子，按权重随机抽3种**不同**动物，玩家三选一。池中同一动物可出现多次（权重更高）。三选一使特定动物出率高于单抽概率，但仍不确定——以此为募兵手段必须按动物混搭设计，或靠亚文化联动保底（见下节）。
- **新版本实测：草地（默认）地形由三选一改为四选一**；其他地形仍按三选一理解，如有出入以实测为准。
- 可用地形改造法术改变所在地形来切换池子，也可用来SL刷新随机结果。

### 低级动物池（呼唤狂野动物，T1/T2）要点

- 默认池：利嘴鸦×4、血獠兽幼崽×4、鳄鱼×2、巨型甲虫×2、座狼、剑脊兽、棕熊、大象、猎人蜘蛛、恐惧/吸血蜘蛛幼崽、织网蜘蛛、双足飞龙幼体、蹒跚幼体、狮鹫、天界狮鹫、猿猴等。
- 寒冷池有寒冰蜘蛛、北极熊、恐怖企鹅；火焰池有腐食鹫、地狱幼犬×3、废品隐士、大象、火焰飞蛾（火焰飞蛾仅火焰池与地下火窟池）；水域池有尼姆、孽障克拉肯、恐怖企鹅、鳄鱼、霜冻鳐鱼、闪电符文蟹、狂鱼群。

Manta 1.2 修复了两种呼唤动物法术对《白银之海》水生动物的召唤。以上低阶新增三种、高阶新增两种，分别由对应法术的 `summoned_units` 确认；数据库未给出这五种动物的抽取权重。[Manta 1.2 更新说明](https://steamcommunity.com/games/1669000/announcements/detail/676263871310201000)

## 原初文化亚文化联动（用户实测）

原初文化使用呼唤狂野/高级动物时，**三选一的第一个选项固定替换为亚文化对应动物，无视地形**（用户实测确认适用于全部亚文化）：

| 亚文化 | 呼唤狂野动物（低阶）第一个替换 | 呼唤高级动物（高阶）第一个替换 |
|---|---|---|
| 风暴乌鸦 | 利嘴鸦 | 雷霆鸟 |
| 森灵之狼 | 座狼 | 白狼 |
| 冰川猛犸 | 大象 | 猛犸 |
| 掘穴蜘蛛 | 各种蜘蛛 | 各种蜘蛛女族长 |
| 沼泽鳄鱼 | 鳄鱼 | 瘟疫鳄鱼 |
| 灰烬剑齿虎 | 无低阶替换 | 剑齿虎 |
| 沙丘巨蟒 | 瘟疫巨蛇或风暴巨蛇（随机出现） | 无高阶替换 |

设计含义：

- 以某高阶动物为主战核心时（如雷霆鸟），选对应亚文化可**无视地形**保底量产，比地形法术+SL稳定得多。
- 选错亚文化会污染第一个选项：例如要雷霆鸟却选了灰烬剑齿虎，第一个选项被剑齿虎占掉，实际只剩2选1，目标出率大降。
- 亚文化提供的是"对应动物"而非一定是同种：猛犸低阶给大象、巨蟒低阶在两种蛇间随机。

## 城市生产动物的特殊途径

- **生灵圣所**（野兽魔典建筑）：城市募役血獠兽幼崽、恐惧蜘蛛幼崽、吸血蜘蛛幼崽（三种幼崽均可进化为对应女族长）、剑脊兽、座狼。
- **蜘蛛巢穴**（织网者魔典 T3 建筑）：生产多种蜘蛛——吸血、恐惧、寒冰、织网、猎人。
- **祭仪篝火**（炎术魔典建筑）：解锁地狱幼犬。
- **双足飞龙巢穴**（巨龙魔典 T3，矿场升级建筑）：解锁双足飞龙招募，种类随品性变化。
- **灵魂熔炉**（吸血鬼领袖体系建筑）：生产吸血蜘蛛幼崽、末日蝙蝠、尖啸蝙蝠、吸血蜘蛛女族长；均需先建灵魂熔炉，且招募消耗奴隶资源。
- **恶魔之门**（传送器升级建筑）：生产地狱猎犬、梦魇兽、地狱主宰（均带动物标签）。
- **唤潮者**（1点社会特性，+1星辰）：可在城邦以折扣价征募闪电符文蟹、霜冻鳐鱼、海马、风暴符文蟹；水上战斗开始时随机水系主题单位加入（等级基于王都等级）。
